## Problem

Three client teams did repetitive knowledge work by hand. An education agency made social and blog content one piece at a time. An event agency researched each public tender and built the bid deck from scratch. A credit rating agency sifted through large volumes of data from several sources.

## What I built

I lead AI implementation for all **3** companies. For the education agency, I automated the content workflow across YouTube, Instagram, Facebook, and the blog. For the event agency, I built a pipeline on LangGraph over their own knowledge base that screens new public-tender postings and drafts the proposal deck. For the credit rating agency, I built a pipeline that pulls data from many sources and lays it out as visual lists. I also trained each team on Claude Code so they can extend the automations themselves.

## Architecture

Each client gets its own knowledge base, so nothing is shared between companies. LangGraph workers read that knowledge, do the research or analysis step by step, and produce the output the team needs: a post, a deck, or a list. Claude Code skills give staff a simple way to adjust the workers.

```
Per-client knowledge base → LangGraph workers → posts, bid decks, visual lists → Claude Code skills for the team
```

## Result

- Reels and blog production: **2-3 days to 1-2 hours**
- Bid research and deck per tender: **1-2 days to 2-3 hours**
- **3** client teams trained to extend the automations on their own
