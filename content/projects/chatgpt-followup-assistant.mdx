## Problem

When I studied with ChatGPT, long answers raised questions that I forgot by the time I finished reading. Typing them later, without the original context, made the conversation scattered.

## What I built

I built a Chrome extension that captures those questions as they come up. Select any text in an answer and add it as a follow-up with **1 click**. The questions collect in a side panel where you can review, edit, reorder, and delete them. When you are ready, one click sends the whole list back into the conversation. It has English and Korean templates, and everything stays in the browser with no outside server. I built it for myself, then polished and published it.

## Architecture

The extension is plain JavaScript, HTML, and CSS. It reads the ChatGPT page, watches for changes as answers stream in, and adds its own panel styled to match. Questions are saved with the Chrome storage feature, so nothing leaves the user's computer.

```
Chrome extension → page observer → side panel UI → Chrome storage → export back into the chat
```

## Result

- Published on the Chrome Web Store
- **2** languages supported, English and Korean
- **0** external servers, all data stays in the browser
