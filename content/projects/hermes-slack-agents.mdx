## Problem

Reports were pulled by hand from separate tools, onboarding new hires took senior staff hours of one-on-one time, and non-engineers had no easy way to ask the company's data a question.

## What I built

I built Hermes, a Slack platform where AI agents do this work in the channels people already use. Agents fix bugs, post daily marketing and data reports, and answer office staff. A chatbot takes newcomers' questions. I also set up Claude Code subagents and skills for each team and trained them. Marketing got an ad pipeline from research to posting. Design got AI design tools. Product managers got a pipeline that turns a feature idea into clarifying questions, a branch, a tech spec, and GitHub issues. Automated deploys, error alerts, and daily tests run on GitHub Actions, Sentry, and Slack.

## Architecture

A message in Slack goes to a router that picks the right agent for the job: bug fix, report, or question. Each agent reaches the code repositories, data, and Slack through its own limited access, then replies in the thread. Team skills sit beside it so each department can tune its own workflow.

```
Slack → agent router → task agents (bug fix, report, Q&A) → repos, data, Slack replies
```

## Result

- **2-3 hours** saved per person daily
- Ad production: **2-3 days to half a day**
- 1:1 onboarding: **2-3 hours to 30 minutes**
- Production issues caught: **2-3 per week** before users reported them

## Troubleshooting

Problem: production errors were going unnoticed until users complained. Cause: nothing connected the deploys, the error tracker, and the channels the team reads. Fix: I wired GitHub Actions, Sentry, and Slack together so each issue became a real-time alert. Result: **2-3 issues per week** are now caught before users report them.
