## Problem

Happy hour deals are popular but scattered across many restaurant sites and social accounts. Diners have to hunt for them, and small restaurants have few ways to promote the deals that fill their quiet hours.

## What I built

I built HappyHour Map, a live web app that shows nearby deals and filters them in real time by time, distance, cuisine, and deal type. It is a responsive React and TypeScript front end with a Node.js backend, and it uses the Google Maps API for location. To fill it with data, I wrote a collection pipeline in Python that scrapes the web and uses a local AI model on LangChain to pull out the deal details and standardize them. This cut manual data entry by over **85%**.

## Architecture

Pages are rendered on the server for the first load, which helps search engines find them, then the browser takes over for filtering. The data pipeline runs separately and writes cleaned deals into the database that the app reads.

```
Python scraper → local LLM extraction → database → Node.js API → React app with Maps
```

## Result

- **4** live filters: time, distance, cuisine, deal
- Manual data entry cut by over **85%**
- SEO metrics up **45%**, with load times under **2** seconds
